# 可靠性控制的双尺度兼容修正

## 1. 问题与设计原则

IGNN+SFD 能够学习多 hop 节点表示，但分类器本身没有显式利用“中心类别与邻居类别之间的兼容关系”。仅使用一个全局兼容强度会假设所有节点同等信任图结构；完全自由的节点 MLP 又容易退化成第二个分类器。

最终方法对局部分支加上两个约束：

1. 它只能调节兼容证据的强度，不能自由生成新的类别方向；
2. 它在节点维度上的均值为零，因此全局分支负责平均修正，局部分支只学习节点偏差。

## 2. 兼容证据

设 backbone logits 为 `Z`，`P=softmax(Z)`。训练节点的概率替换为真实 one-hot 标签，未标注节点保留预测概率，得到 `Pseed`。根据 CMGNN 置信度/度数估计得到行归一化兼容矩阵 `C`，然后计算：

```text
E = normalize(A Pseed C^T)
Q = center(log(E))
B = center(log(P))
```

`Q` 是经兼容矩阵转换后的图结构证据。

## 3. 全局修正

```text
s = smax * sigmoid(θ)
Zglobal = Z + s Q
```

`s` 是所有节点共享的有界强度，描述整张图平均应该信任多少兼容证据。

## 4. 节点局部修正

共享关系 MLP 使用：

```text
r_i = [B_i || Q_i || |Q_i-B_i| || B_i⊙Q_i]
u_i = tanh(MLP(r_i))
δ_i = λ/2 * (u_i - mean_nodes(u))
Zlocal = Z + δ_i ⊙ Q_i
```

`δ_i` 是 node-wise、class-wise 的有符号系数，范围为 `[-λ,λ]`，且每个类别通道在所有节点上的均值为零。它只表示“某个节点相对全局平均应该多信或少信兼容证据”。

## 5. 双尺度与可靠性控制

```text
Zdual = Z + (s + δ_i) ⊙ Q_i
```

局部 MLP 的末层零初始化，所以训练初始时 `Zdual=Zglobal`，删除局部项可以精确退化为全局模型。

不同 split 中图结构证据的可靠性存在差异。最终输出只根据 validation accuracy 在 `global` / `local` / `dual` 三个状态中选择，平局时优先更保守的 `global`，其次 `local`，最后 `dual`。选择器不接收数据集名称，不读取 test 标签。

## 6. 严格消融

所有分支使用同一 SFD checkpoint、split、seed、训练轮数、early stopping 和 validation checkpoint 规则。表中“去极值平均”是先计算 8 个数据集各自的 10-split 平均配对增益，再删除最高和最低数据集，对剩余 6 个求平均。

| 模型 | 宏平均增益 (pp) | 去极值增益 (pp) |
|---|---:|---:|
| SFD | 0.0000 | 0.0000 |
| classifier-only | +0.2208 | +0.0060 |
| 仅全局修正 | +0.2774 | +0.0815 |
| 仅节点局部修正 | +0.1910 | +0.0169 |
| 固定全局+局部 | +0.2823 | +0.0806 |
| **可靠性控制双尺度** | **+0.3443** | **+0.1050** |

消融表明：全局分支是主要稳定增益来源；局部分支单独使用较弱；固定启用局部分支在宏平均上略有改善，但去极值后与全局分支持平；可靠性控制避免了不可靠局部修正，是完整双尺度系统超过单一分支的关键。
