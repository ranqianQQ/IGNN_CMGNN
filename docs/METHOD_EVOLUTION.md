# 方法演变与最终取舍

## 1. IGNN 主干

项目始终保留 IGNN 的三阶段结构：

- SN：从图结构中生成不同 hop 的邻域表示；
- IN：在层内更新和变换节点表示；
- NR：融合多 hop 表示并输出节点表征。

后续模块建立在该主干上，没有为某个数据集替换 SN、IN、NR 或 classifier。

## 2. SFD：带符号频率解耦

SFD 显式利用相邻 hop 的变化：

```text
Delta h_k = h_k - h_(k-1)
h_tilde_k = h_k + tanh(g_k) * Delta h_k
```

`tanh(g_k)` 是逐通道带符号门控，可增强或抑制相邻 hop 的变化。调制后的全部 hop 仍进入 IGNN 原有的融合与分类路径。因此 SFD 是对多尺度表示的频率解耦，而不是额外分类器。

## 3. 引入类别兼容关系

异配图中，邻接节点往往属于不同类别。仅按同配假设聚合会混淆类别信息，因此在 SFD logits 后引入 CMGNN 风格的兼容矩阵 `C`。`C_ab` 描述类别 `a` 节点与类别 `b` 邻居相连的倾向，并根据模型软预测、训练标签与图结构估计，不读取 validation 或 test 标签。

对主干概率和训练标签组成的种子分布 `P_seed`，计算：

```text
E = normalize(A P_seed C^T)
Q = center(log(E))
```

最终用有界全局强度修正原 logits：

```text
Z_out = Z + s Q
```

这形成完整模型：

```text
IGNN (SN + IN + NR) -> SFD -> classifier -> fixed global compatibility correction
```

## 4. 探索过但未进入最终模型的形式

实验曾检验以下实现：

- 直接逆兼容矩阵解码；
- 兼容一致性损失；
- 基于兼容关系的边重加权；
- likelihood-ratio 修正；
- 标签传播式局部修正；
- ridge 双尺度修正；
- 节点局部 MLP 和固定全局+局部双尺度。

这些形式在统一的快速筛选或完整消融中没有稳定超过固定全局修正，因此不进入最终模型。

还检验过根据每个 split 的 validation accuracy 在 `global / local / dual` 三个预测头之间选择结果。该做法会把模型定义变成数据划分级选择规则，不能作为统一模型结构。最终结果不使用该选择器；相关记录只属于被否决的历史实验。

## 5. 为什么最终只保留全局修正

完整 8 数据集 × 10 splits 消融结果为：

| 方法 | 宏平均增益 (pp) | 去极值平均增益 (pp) |
|---|---:|---:|
| classifier-only | +0.2208 | +0.0060 |
| **固定全局** | **+0.2774** | **+0.0815** |
| 仅局部 | +0.1910 | +0.0169 |
| 固定双尺度 | +0.2823 | +0.0806 |

固定双尺度没有改善去极值主指标，说明节点局部修正在当前实验中不是必要组成。最终方法因此采用结构更简单、主要贡献更清楚的固定全局兼容矩阵修正。

## 6. 当前结论边界

最终固定模型在 8 个数据集上的宏平均配对增益为 `+0.2774 pp`，去掉最高和最低数据集后的平均增益为 `+0.0815 pp`，7/8 个数据集平均为正。它说明“IGNN 多 hop 表征解耦 + 类别兼容关系修正”是可运行且多数数据集有弱正信号的统一方案，但现有结果达不到去极值 `+0.5 pp`，也不能宣称普遍显著提升。
